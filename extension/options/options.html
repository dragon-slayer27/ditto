Your Ditto profile

Everything Ditto knows about you lives in this browser on this computer. Gemma reads it locally through Ollama when you ask Ditto to fill a form. Nothing is uploaded, ever.

Teach Ditto in one go

Paste a resume, an old form you filled, or just write a few lines about yourself. Gemma pulls out the facts, and you choose what to keep.

    Facts

    Short, plain labels work best ("Father's name", "Emergency contact phone"). Changes save automatically.

    Try it with a demo person

    Load Meera Iyer, a fictional person with about 50 facts, then open the demo forms (a job application, a bank KYC form, a clinic intake, a rental application and a hackathon sign-up) and press Alt+Shift+D.

    Open the demo forms

    Model and connection

    Don't have it yet? Install Ollama, then run ollama pull gemma4:e4b (or gemma4:e2b on machines with 8 GB of RAM).

    Page memory

    After a page is filled once, Ditto remembers which answer goes where, so the same form fills instantly next time.
